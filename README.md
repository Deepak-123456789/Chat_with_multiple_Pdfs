# 📄 Chat with Multiple PDFs

An intelligent chatbot that allows you to upload multiple PDF files and interact with them using natural language. Powered by LangChain, FAISS, and genai language models, this app can extract, embed, and query content from PDFs to give insightful, context-aware answers.

## 🚀 Features

- 📚 Upload and chat with multiple PDF files at once.
- 💬 Ask questions across all uploaded documents.
- ⚡ Fast and efficient retrieval using FAISS vector database.
- 🧠 Natural language understanding powered by Google GenAI.
- 🖥️ User-friendly interface built with Streamlit.

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- PyPDF2
- Google GenAI
